# Changelog

## 1.2.0 — 2026-10-09

- Add synth-independent score cues, state changes, arbitrary markers, and camera routes.
- Add normalized /rack/control mappings and transport reset messages.
- Share protocol helpers between live performance and baked score paths.
- Update packaging, documentation, and the companion Generant workflow.

## 1.1.0 — 2026-09-07

- Receive timestamped live OSC note, parameter, free, and choke events over UDP.
- Show active instruments, notes, voices, and recent events in Blender's sidebar.
- Create a generic reactive visual rig for arbitrary instrument tracks.
- Build a 1080 × 1920 portrait tunnel with bass tiles, pad-driven glass walls, and pooled drum rings.
- Bake text OSC scores into deterministic 30 fps animation with a seamless 800-frame loop.
- Support both native SuperCollider and Ambient Companion SynthDef prefixes in the performance baker.
- Add a repeatable packaging script, parser tests, and a Blender scene smoke test.
