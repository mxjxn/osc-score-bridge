The add-on is a Blender-side runtime. It owns the UDP listener, event state, mappings, score cues, and baked animation data.

Registration

__init__.py registers the Blender properties, operators, panels, live receiver, cue system, and performance scene tools. Blender calls register when the add-on is enabled and unregister when it is disabled.

Live path

live.py receives OSC datagrams on a Blender timer. Packets are decoded, timestamped events are queued, and due events are dispatched to note, control, reset, or cue handlers.

Baked path

parser.py reads text scores. baker.py remaps values and inserts keyframes. cues.py stores string state, markers, camera routes, and score-owned animation on a dedicated scene object.
