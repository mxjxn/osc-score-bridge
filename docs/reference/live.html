02 / LIVE RECEIVER

Live events
with timing.

Live preview is intended for setup and performance. The receiver follows timestamped bundles and applies due events from Blender's UI timer.

Listen

Open the OSC Bridge panel in the 3D View sidebar and click Listen. The default port is 57141. The dashboard reports received events, active tracks, voices, and the latest error.

Voice state

Note messages create voice records keyed by node id. Set messages update parameters or close a gate. Free and choke messages remove voices. Explicit duration, decay, and legacy drum lifetimes are handled by the shared protocol helpers.

Controls

/rack/control accepts a name and normalized value. The bridge stores the latest value, resolves matching mappings, remaps the range, and writes the target property. Values are clamped to 0..1 before mapping.

Reset

/rack/reset, /companion/reset, and /transport/reset clear queued events, active voices, controls, and cue state. Use reset when restarting a sender or changing a performance scene.
