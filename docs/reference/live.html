01 / LIVE OSC

Receive OSC while Blender is open

Start the listener

  1. In Blender, open a 3D View and press N.
  2. Open the OSC Bridge tab.
  3. Set the port to the sender's destination port. The default is 57141.
  4. Click Listen.
  5. Start playback in Generant or send a test OSC message.

The live panel shows the received event count, recent messages, active tracks, voices, controls, and the last receiver error. If the counter does not increase, check that both programs use the same port and that another process is not already bound to it.

Test a numeric cue

  1. Send an unreserved address with one number, for example /visual/test 0.5.
  2. Select Rack OSC Score in the Outliner. The add-on creates it if it does not already exist.
  3. Open Object Properties → Custom Properties.
  4. Confirm that osc:/visual/test contains 0.5.

Map a live control directly

  1. Send /rack/control scene_energy 0.5.
  2. Create a mapping whose track name is control_scene_energy.
  3. Set the target object, data path, array index, input range, and output range.
  4. Send another value. The target property changes immediately; no keyframes are inserted.

/rack/control values are clamped to 0–1 before range mapping. An unreserved address with one numeric argument can also apply a mapping whose track name is the complete OSC address.

Reset or stop

Send /transport/reset, /rack/reset, or /companion/reset to clear scheduled events, active voices, controls, and cue state. Click Stop before an offline render so live packets cannot change the scene during rendering.
