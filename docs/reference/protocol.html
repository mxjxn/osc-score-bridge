OSC messages and their results

Live performance messages

AddressArgumentsBlender result
/companion/notetrack, node ID, synth name, parameter/value pairsCreates or replaces a live voice. The dashboard and automatic track visual update.
/companion/settrack, node ID, parameter/value pairsUpdates that voice. gate 0 removes it.
/companion/freetrack, node IDRemoves the voice.
/companion/choketrackRemoves active type 2 and 3 voices on the track.
/rack/controlname, normalized valueStores a value clamped to 0–1 and applies mappings whose track is control_name.
/rack/reset, /companion/reset, /transport/resetnoneClears queued events, voices, controls, cue values, and live performance state.
any other addresszero or more valuesCreates or updates osc:/address on the Rack OSC Score Empty. Numeric first arguments can also feed a live mapping whose track matches the address.

Generant score JSON

Each exported event contains seconds, address, args, and kind. Events must be sorted, occur at or after zero, and occur before durationSeconds.

{
  "format": "rack-osc-score",
  "version": 1,
  "durationSeconds": 10,
  "events": [
    {"seconds": 0, "address": "/visual/kick", "args": [1], "kind": "event"},
    {"seconds": 0.08, "address": "/visual/kick", "args": [0], "kind": "curve"}
  ]
}
KindUseImport behavior
eventA discrete hit or manually placed cue.Bakes the value and adds a timeline marker.
stateA value intended to remain active until it changes.Bakes the value and adds a timeline marker.
curveDense automation or sampled values.Bakes numeric values without adding timeline markers.

The importer treats the argument shape separately from the kind: no arguments become a counter; one number becomes a numeric F-Curve; strings and multiple arguments are restored from embedded score data while scrubbing.
