03 / PROTOCOL

Addresses and
score lines.

Generant and other senders can use the performance messages or send independent score cues. Addresses outside the reserved namespaces are available to the cue system.

Performance messages

AddressArgumentsAction
/companion/notetrack, node, synth, pairsStart voice
/companion/settrack, node, pairsUpdate voice
/companion/freetrack, nodeEnd voice
/companion/choketrackChoke voices
/rack/controlname, valueApply control mapping

Score lines

0.0 /companion/note bass 12 sine freq 55 amp 0.4
0.5 /rack/control kick 1.0
1.0 /song/part1
1.5 /companion/free bass 12

Timestamped OSC bundles preserve event time. Text scores use one timestamped message per line. Generant exports ordered song positions and standalone OSC tracks on the same timeline used for playback.
