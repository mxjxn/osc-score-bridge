The standalone repository is canonical. Generant packages this checkout when preparing its bundled Blender add-on.

Important modules

  • live.py — UDP receiver, timer queue, controls, and dashboard.
  • cues.py — score cues, markers, string state, and baking.
  • baker.py — range mapping and Blender keyframes.
  • parser.py — text score parsing.
  • protocol.py — timing, reset, normalized values, and voice lifetime.
  • performance_scene.py — supplied visual rig.

Checks

python3 -m unittest discover -s tests -v
python3 -m py_compile *.py
./scripts/package.sh

The package script produces dist/osc_score_bridge-1.2.0.zip. Blender smoke tests require Blender; parser and protocol tests do not.
