05 / DEVELOPMENT

Test and package the add-on

Run the Python tests

python3 -m unittest discover -s tests -v

These tests cover parsing and protocol behavior without starting Blender.

Run the Blender smoke test

blender --background --factory-startup --python tests/blender_smoke.py

This requires Blender on the command path. It checks registration, scene creation, score baking, and loop closure.

Build the installable zip

./scripts/package.sh

The package is written to dist/osc_score_bridge-1.2.0.zip. Install that zip through Blender's add-on preferences.

Repository relationship

mxjxn/osc-score-bridge is the source repository. Generant's packaged bridge copy is a release artifact. Make bridge changes here, test them here, then run Generant's bridge packaging helper when Generant needs an updated bundled copy.
