04 / MAPPING AND BAKING

Turn values
into animation.

A mapping defines the source track or control, its input range, and a Blender target data path with an output range.

Mapping values

Input values are remapped from the source range to the target range. Step interpolation is useful for triggers, linear interpolation for continuous controls, and Bezier for shaped motion. One source can drive multiple targets.

Bake ownership

The baker writes numeric state to custom-property keyframes on the scene's Rack OSC Score Empty. Camera cues become timeline markers. String and multi-argument states remain in an embedded score text and are reconstructed while scrubbing.

Render workflow

  1. Export the score from Generant.
  2. Import it in the OSC Bridge panel.
  3. Configure mappings and camera routes.
  4. Bake and inspect the score-owned object.
  5. Stop live listening before rendering.

For a seamless loop, make the final baked state equal the first state and omit the duplicate endpoint frame from the encoded video.
