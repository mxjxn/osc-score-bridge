WORKFLOW

01

Preview live

Listen on UDP 57141 and inspect incoming tracks, notes, controls, and voices in Blender. Use mappings to connect values to object properties.

02

Bake the score

Load an OSC score exported by Generant, map its values, and create keyframes, custom properties, camera markers, and cue state in the scene.

03

Render offline

Stop the receiver before rendering. The baked scene is the deterministic source for animation and does not depend on audio hardware or live UDP timing.

0.5 /rack/control kick 1.0 1.0 /song/part1 1.5 /companion/free bass 12

EVENTS

Any event can be a visual input.

A note-on, note-off, knob turn, envelope value, sampled curve, or arbitrary marker can drive an object, light, camera, material, or custom property.

INSTALL

Install the add-on in Blender.

Download a release zip or clone the repository. In Blender, open Preferences → Add-ons → Install from Disk, enable OSC Score Bridge, and open the OSC Bridge tab in the 3D View sidebar.

Open the technical reference ↗
$ git clone https://github.com/mxjxn/osc-score-bridge
$ cd osc-score-bridge
$ ./scripts/package.sh
