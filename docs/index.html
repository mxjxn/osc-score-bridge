OSC Score Bridge

The add-on receives OSC while Blender is running and imports OSC score data as F-Curves, custom properties, and timeline markers. Generant can export the JSON score format used by the cue importer.

Example: drive a Blender light from a kick cue

1 · SCORE EVENT
/visual/kick 1

Send 1 on the kick and 0 shortly afterward.

2 · IMPORTED PROPERTY
Rack OSC Score
["osc:/visual/kick"]

The score importer creates and keyframes this custom property.

3 · BLENDER DRIVER
kick * 1500

A driver on the light's Power reads the property. The cue produces 1500 W; the release returns it to 0 W.

  1. Import the Generant OSC score in the Generant Cues panel.
  2. Right-click the light's Power property and choose Add Driver.
  3. Add a Single Property variable named kick. Set its object to Rack OSC Score and its path to ["osc:/visual/kick"].
  4. Set the driver expression to kick * 1500.

Install

  1. Download an add-on zip from the repository releases, or clone the repository and run ./scripts/package.sh.
  2. In Blender, open Preferences → Add-ons → Install from Disk.
  3. Select the zip and enable OSC Score Bridge.
  4. Open a 3D View, press N, and select the OSC Bridge tab.

Sequencers and the bridge

Generant sequences music and arbitrary OSC events. The Generant OSC Renoise tool sends and exports the same score format from Renoise effect columns and automation. OSC Score Bridge receives either source live or imports its exported score into Blender. The imported data can drive lights, transforms, shaders, Geometry Nodes, modifiers, cameras, or custom scripts.
